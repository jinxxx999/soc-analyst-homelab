# Wazuh Indexer (Elasticsearch) Installation Guide
## Overview
The Wazuh Indexer is a highly scalable, full-text search and analytics engine based on OpenSearch (Elasticsearch fork). It is responsible for storing, indexing, and searching the security data generated by the Wazuh Manager.

## Components
Wazuh Indexer (v4.14.1): Core engine for data indexing and storage.

## Prerequisites
Docker and Docker Compose installed.

System Memory: Minimum 4GB RAM dedicated to this container (8GB recommended for stable performance).

**Kernel Settings:** vm.max_map_count should be set to at least 262144 on the host machine.

---

## Installation Steps
### Preparation

Ensure the lab-setup directory exists and contains the necessary configuration files.

```Bash
cd lab-setup
```
### Service Configuration

The Indexer is defined in the docker-compose.yml file. It uses certificates for secure communication with the Manager and Dashboard.

### Start the Indexer

Run the following command to start the service in detached mode:

```Bash
docker-compose up -d wazuh-indexer
```
### Verification

Check if the service is up and the health status is green:

```Bash
docker ps | grep wazuh-indexer
```
You can also verify the API response:

``Bash
curl -u admin:SecretPassword -k https://localhost:9200
```
## Troubleshooting
# Container exits with Error 137

This is usually an Out of Memory (OOM) error. Increase the RAM limit in Docker Desktop settings.

# Bootstrap check failed

If you see "max virtual memory areas vm.max_map_count [65530] is too low", run this on your host machine:

```Bash
sudo sysctl -w vm.max_map_count=262144
```
